# TypeScriptとFlowについて、どちらが主流となっているかを調べなさい。

## 解答

TypeScriptが主流である。

## 調査結果

- https://www.npmjs.com/package/typescript と https://www.npmjs.com/package/flow-parser の Weekly Downloads を比較すると、TypeScript の方が10倍以上多い。
- https://github.com/microsoft/TypeScript と https://github.com/facebook/flow の Watch や Star を比較すると、TypeScript の方が5倍程度多い。

# また、その理由を考えてまとめなさい。

## 解答

- Microsoft による継続的な開発とメンテナンスが行われており、特に同じ Microsoft 製 IDE の VS Code との統合性が高い（IntelliSense の自動補完やエラーメッセージの分かりやすさなど）
- Angular、React など、多くのライブラリやフレームワークが TypeScript を公式にサポートしている。
- ほぼすべての主要JavaScriptライブラリの型定義が利用可能である。
- TypeScript の方がコミュニティが大きくアップデートも頻繁に行われている。
